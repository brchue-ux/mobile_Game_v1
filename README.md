# Mobile Game (working title)

Real-time mobile lane-battler with compound spellcasting.
**Concept design stage — no code yet.**

## Where the design lives

- [`.scratch/core-concept/map.md`](.scratch/core-concept/map.md) — the canonical
  design artifact. Read this first.
- `.scratch/core-concept/issues/` — the 18 concept tickets that feed the map.
- `.scratch/core-concept/prototypes/` — throwaway HTML prototypes.
- [`CONTEXT.md`](CONTEXT.md) — ubiquitous-language glossary of domain terms.
- [`CHANGELOG.md`](CHANGELOG.md) — session narrative. Grep it for a past decision,
  a reversal, or why something was tried.
- [`AGENTS.md`](AGENTS.md) (aliased as `CLAUDE.md`) — working agreement and
  current ticket state.

## Method

One ticket per session. The map is rebuilt rather than traversed, one commit per
rebuild, so every prior version stays diffable.

Engine, stack, platform, and name are deliberately undecided until the concept
settles.
